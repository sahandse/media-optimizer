# Media Optimizer

افزونه بهینه‌سازی حرفه‌ای تصاویر وردپرس با پنل فارسی و مرکز پردازش یکپارچه.

## Version 1.3.1

- پردازش گروهی 30/50 تصویر با صف پایدار و Pause/Resume
- نمایش تصاویر انجام‌شده، باقی‌مانده، خطاها و درصد پیشرفت
- WebP / AVIF با تشخیص پشتیبانی سرور
- Smart Quality و حالت‌های Manual / Lossless / Balanced / Maximum
- Resize خودکار، حذف EXIF/Metadata و حداقل درصد صرفه‌جویی
- Backup و Restore + پاک‌سازی بکاپ‌های قدیمی
- اسکن تصاویر تکراری و بدون‌استفاده احتمالی
- Lazy Load، WooCommerce mode و زمان‌بندی ساعتی/روزانه/هفتگی
- ستون صرفه‌جویی در Media Library

مسیر مدیریت: **رسانه ← بهینه‌ساز رسانه**
