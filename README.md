# بهینه‌ساز رسانه

افزونه بهینه‌سازی تصاویر وردپرس با پردازش دسته‌ای، تبدیل WebP/AVIF و کنترل کیفیت.

## ویژگی‌ها
- پردازش دسته‌ای ۳۰ یا ۵۰ تصویر
- تبدیل خودکار تصاویر جدید
- WebP و AVIF
- انتخاب کیفیت
- نمایش میزان صرفه‌جویی
- Restore نسخه اصلی
- حذف نسخه‌های اضافی
- مقایسه قبل/بعد
- زمان‌بندی بهینه‌سازی
- رابط فارسی و مینیمال
