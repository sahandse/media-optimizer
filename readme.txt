بهینه‌سازی تصاویر وردپرس با تبدیل WebP/AVIF، پردازش دسته‌ای و Restore.

== Description ==
Media Optimizer provides a Persian-first image optimization foundation with configurable output format, quality and batch size.

== Installation ==
1. Upload the media-optimizer folder to /wp-content/plugins/
2. Activate the plugin.
3. Open بهینه‌ساز رسانه from WordPress admin.
